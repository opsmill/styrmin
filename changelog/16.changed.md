Changed the agent and operator settings (poll retries and intervals, status poll interval, reconcile interval, deployment ready timeout, peering, deleted StyrminDeployment retention and janitor interval) to load with the other Styrmin settings: they keep their environment variable names, can also be set in `styrmin.toml` under `[agent]` and `[operator]`, and appear in `styrmin config show`. Removed `STYRMIN_OPERATOR_HR_READY_TIMEOUT`, which had no effect. A value below 1 for a poll interval, the reconcile or janitor interval, or the deployment ready timeout is now rejected when the settings load, instead of making a poll loop run without waiting.
