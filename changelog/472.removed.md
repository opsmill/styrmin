Removed the `node_selector` setting from cluster and deployment configuration, and the `nodeSelector` field from the `UpdateClusterInput`, `UpdateDeploymentInput` and `DeploymentConfigInput` GraphQL inputs. Styrmin stored the value but never applied it to a pod. To place pods on nodes by label, set `scheduling.node_affinity` on the environment or the deployment. `styrmin db migrate` deletes the stored values.
