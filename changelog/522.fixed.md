Fixed the Python SDK dropping the extensions of a GraphQL error: the exceptions it raises, such as `OperationFailedError`, now give all the extensions that the server returned in an `extensions` attribute, so a program can read, for example, the `path` of a refused affinity term or the `deployments` of a refused clone request without parsing the message. An error with `extensions: null` now raises the matching SDK exception with the server's message instead of `AttributeError`.
