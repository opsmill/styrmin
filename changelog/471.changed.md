Changed how the Ingress class of an application is set: Styrmin now sets the class of every Ingress after the chart renders, or removes `spec.ingressClassName` when the environment has a dedicated ingress controller, so driver templates no longer need to set it, and the `simple-app`, `semaphore` and `slurpit` example drivers no longer set it. With a dedicated ingress controller, Styrmin now also removes a class that the chart sets on its own, so such a chart deploys there; before, Kubernetes rejected its Ingress, or the dedicated ingress controller ignored it. Driver templates now read the resolved `ingress_class` with a dedicated ingress controller too, where it was empty before.
