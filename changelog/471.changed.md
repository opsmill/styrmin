Changed how Styrmin handles the Ingress class with a dedicated ingress controller: after the chart renders, Styrmin now removes `spec.ingressClassName` from every Ingress of the application, so a chart that sets its own class deploys there; before, Kubernetes rejected its Ingress, or the dedicated ingress controller ignored it. Driver templates now read the resolved `ingress_class` with a dedicated ingress controller too, where it was empty before. Driver templates no longer need to set the Ingress class, and the `simple-app`, `semaphore`, `slurpit` and `generic-app` example drivers no longer set it.
