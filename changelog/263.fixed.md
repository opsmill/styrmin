Fixed backups of the example `infrahub` driver ending `PartiallyFailed` without the database: its database component ran an Enterprise-only Neo4j command against the Neo4j Community image that the Infrahub chart deploys. Driver version 4 uses the `neo4j-community` backup kind. Deployments stay on driver version 3 until an operator moves them to version 4, for example with `styrminctl deployments update-version`. That move removes the `backup` volume from the Neo4j pod template, so Kubernetes restarts Neo4j. Backups taken with driver version 3 do not contain the database.
