Removed the `scheduling` setting from cluster configuration, the `scheduling` field from the `UpdateClusterInput` GraphQL input, and "Scheduling defaults" from the cluster page. Styrmin stored the cluster value but never applied it to a pod. `createCluster`, `styrminctl clusters create` and `styrminctl clusters update` now refuse a cluster config that sets `scheduling`: set it on the environment or the deployment instead. `styrmin db migrate` deletes the stored values.
