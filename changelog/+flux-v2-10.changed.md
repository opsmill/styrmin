Changed the FluxCD controllers that the agent chart installs from helm-controller v1.6.5 and source-controller v1.9.6 (Flux v2.9.6) to helm-controller v1.7.1 and source-controller v1.10.1 (Flux v2.10.0). When a change of env vars or image overrides fails before Helm stores a release, for example because the component container is not found, helm-controller now keeps the HelmRelease not ready and tries again, instead of reporting the previous release in sync ([fluxcd/helm-controller#1607](https://github.com/fluxcd/helm-controller/issues/1607)). The agent therefore no longer reads FluxCD's Kubernetes Events, and its ClusterRole no longer allows `list` on `events`. The FluxCD project supports Flux v2.10 on Kubernetes 1.35.2 and later.
