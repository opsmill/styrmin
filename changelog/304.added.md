Added the application version of each backup to a deployment's backup history: an "Application version" column on the Backups tab, an `application_version` column in `styrminctl backups list`, an "Application version" line in `styrminctl backups get`, and `instance.applicationVersion` in the API and SDK. The Backups tab marks the backups of the current instance, shows the time each backup was created, marks a backup whose expiry date has passed as "Expired", and shows an error with a "Try again" action when the list cannot be loaded. API users can list a deployment's backup history with `backups(deploymentId:)`, and SDK users with `list_backups(deployment_id=...)`.
