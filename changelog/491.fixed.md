Fixed changing the service-name override of a deployment leaving an alias with the old name in the namespaces of the other deployments of its environment. Styrmin now labels each alias with the id of the deployment that owns the service (`styrmin.io/deployment-id`) and, each time it creates, updates or upgrades a deployment, deletes the deployment's aliases whose name the deployment no longer uses, including aliases that earlier versions created without the label. The deployment's task shows the step as "Create and delete service aliases".
