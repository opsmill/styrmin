Changed the type of the tasks that a reconcile runs from `noop` (shown as "No-op") to the operation they start: `create_instance`, `update_instance`, `upgrade_instance`, `stop_components` or `start_components`; tasks recorded before keep `noop`, and `delete_deployment` tasks are now shown as "Delete". Changed `runJob` tasks to run through an internal `run_job` flow, which creates an action token for the `styrmin-actions` user and runs the job's command in a new user flow, `run_job_command`, so each `runJob` task now has two flow runs in Prefect and creates one `styrmin-actions` session while it runs; backups and restores also create one such session each.
