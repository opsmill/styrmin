Fixed green indicators that did not depend on the application's pods. The endpoint and component dots on a deployment's Overview tab are now green only when the deployment is running and every pod of the component is ready, the Pods tab shows a running pod that is not ready, for example one in `CrashLoopBackOff`, as `NOT READY` in amber, and an environment shows `Healthy` only when every deployment in it is running, not while one is deploying, restoring or deleting.
