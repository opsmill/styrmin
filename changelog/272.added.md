Added the logo, description and links of each driver to the driver pages. A driver author sets them in `spec.info.icon`, `spec.info.description` and `spec.info.links` of `driver.styrmin.yml`. The driver list page shows the logo of each driver and the first line of its description, and the driver detail page shows the logo, the first three lines of the description and the links of the selected driver version; a "Show more" button shows the rest of a longer description, the driver list filter matches descriptions, and each link shows the host it goes to and opens in a new browser tab. The browser of each person who views the page loads the logo from its URL. The pages show the logo on a white tile, and show the generic package icon until the logo has loaded and when a driver version has no logo or the browser cannot load it. To stop the browser requests to logo hosts, set the Helm value `styrmin.driver.showLogos` (environment variable `STYRMIN_DRIVER_SHOW_LOGOS`) to `false`; the API then returns no logo URL. A driver version loaded before this release gets its logo, description and links when the same driver is loaded again. Available as `icon`, `description` and `links` on `ApplicationDriverVersion` in the API.
