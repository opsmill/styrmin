Added the logo, description and links of each driver to the driver pages. A driver author sets them in `spec.info.icon`, `spec.info.description` and `spec.info.links` of `driver.styrmin.yml`. The driver list page shows the logo of each driver and its description on one line, shortened to fit, and the driver detail page shows the logo, the full description and the links of the selected driver version; each link opens in a new browser tab. The browser of each person who views the page loads the logo from its URL, and a driver version without a logo, or with a logo that the browser cannot load, shows the generic package icon. A driver version loaded before this release gets its logo, description and links when the same driver is loaded again. Available as `icon`, `description` and `links` on `ApplicationDriverVersion` in the API.
