Added loading an application driver from a driver directory of a git repository, so one repository can hold several drivers: `styrminctl drivers load-version --driver-directory`, `driver_directory` on `drivers.load_version()` in the Python SDK, the `driverDirectory` argument of `loadRemoteApplicationDriverVersion` and the "Driver directory" field of the "Load a driver" drawer. The driver version's Overview tab and the drivers list show the driver directory, and the driver's actions run from it and can import only modules inside it. A reload after any commit to the repository creates a new driver version, even when the driver directory did not change. Every load from git, also from the repository root, now fails when the driver directory or its `driver.styrmin.yml`, `values.j2.yml` or `actions.py` is a symlink to a path outside the repository. See [Loading a Driver](https://styrmin.pages.dev/docs/drivers/loading-drivers#loading-a-driver-from-a-driver-directory).
