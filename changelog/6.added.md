Added environment clone: one action copies a live environment into a brand-new environment on the same cluster, built from a fresh backup of the source, with a choice of which deployments to include and a clone-time config override (set or clear captured config fields) so the copy can be made safe before it starts. Available as the `cloneEnvironment` mutation (ADMIN) plus the `environmentClone` / `environmentClones` queries, `client.environment_clones` in the SDK, the `styrminctl env-clones` command group, and a **Clones** tab with a clone dialog on the environment detail page. A clone's status is derived from its backup, the environment it created and the restores into that environment's deployments; deleting the created environment discards the clone.
