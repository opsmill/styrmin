Added a description to backups, and the option to rename a backup and change its description after it is created, in the UI, `styrminctl backups update`, the SDK and the `updateBackup` GraphQL mutation. Backup names are now unique among the backups of one deployment instance instead of across all backups. Velero `Backup` objects are now always named after the backup's id (`styrmin-<backup id>`), so a rename changes no object in the cluster; backups created earlier with a custom name keep their Velero object.
