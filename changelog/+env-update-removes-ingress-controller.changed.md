Changed the environment update so that, when it turns the environment's own `dedicated_ingress` off and the cluster does not set `dedicated_ingress`, Styrmin removes the environment's dedicated ingress controller once the applications have been redeployed to the cluster's `ingress_class`. Before, the controller stayed until the last application in the environment was deleted. Also, when an environment's ingress controller reaches `RUNNING`, Styrmin now redeploys the applications of that environment that are not at the config they resolve to.
