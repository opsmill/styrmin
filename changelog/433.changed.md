Changed the FluxCD controllers that the agent chart installs from helm-controller v1.1.0 and source-controller v1.4.0 to helm-controller v1.6.5 and source-controller v1.9.6 (Flux v2.9.6), which support Kubernetes 1.34.1 and later; helm-controller keeps Helm v3's apply and health checks. Before each install and upgrade, a hook Job of the agent chart now applies the agent's CRDs (`styrmin-agent.crdUpgrade.enabled`), because Helm never updates them: on an existing installation it recreates the unused `OCIRepository` CRD, and fails the upgrade if the cluster has `OCIRepository` objects.
