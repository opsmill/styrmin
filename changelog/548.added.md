Added `client.deployments.get_crd_status()` to the Python SDK. It returns the deployment state and, as `crd_status`, the status of the deployment's `StyrminDeployment` as the agent last reported it: the operator's phase and message, the conditions, the managed resource counts and the time the server received the report. `styrmin_sdk.models` exports the returned types as `DeploymentCrdStatus`, `CrdStatus`, `CrdCondition` and `ManagedResourceCounts`.
