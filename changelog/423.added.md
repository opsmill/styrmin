Added `styrminctl clusters update`, `clusters.update()` in the SDK, the `updateCluster` GraphQL mutation and an Edit button on the cluster detail page, which administrators use to change a cluster's config without recreating the cluster, its environments and its deployments. Styrmin saves the whole new config and redeploys each deployment whose resolved config changes; the result lists the deployments that are redeployed, that wait for a dedicated ingress controller and that could not start, and `--dry-run` (`dryRun`) and the edit dialog's review step list them before anything is saved. `styrminctl clusters get --json` prints the config to edit.
