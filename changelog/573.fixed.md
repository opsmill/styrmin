Fixed passwords and env var values appearing in plain text in Styrmin's logs and in Prefect's log table. The task worker logs which keys of a deployment changed instead of their values, the Infrahub example drivers log the deployment id instead of their context, a failed GraphQL request is logged without the request, and the request log at `DEBUG` masks every variable value except ids and names. Every Styrmin process also replaces common forms of secrets, such as the value after `password:` or `token=`, in each log line, and tracebacks no longer show the values of variables.
