Added `styrmin-driver`, a command installed with the SDK and present in the Styrmin image, that checks, renders and compares an application driver on the author's machine with no server, database or cluster. `check` can report more errors in one run than a load, which stops at the first, each with its file and, when it is known, its line. It also reports the undefined template variables that its render finds, with their line. The server renders such a variable as an empty string or another value with no message, or fails with a message that gives no line.
