Changed how env vars reach pods: a driver now declares one component container per component (`components.<name>.container`), and Styrmin merges the environment, deployment, and component env vars into that container by name after the Helm chart renders, so the chart's own env defaults are kept and a user value replaces a chart entry of the same name. User env vars no longer reach chart Jobs, init containers, or other containers; adding or changing a component env var on a component without a component container is rejected with `COMPONENT_CONTAINER_NOT_DECLARED`; and the HelmRelease spec is replaced on every update, so env values written by an old driver template no longer linger. Every example driver declares its component containers. Rolling Styrmin back below this release stops env var injection for drivers already migrated.
