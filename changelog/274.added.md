Added an anonymous daily telemetry report from the Styrmin server, on by default: once a day at 02:43 UTC the task worker sends the install ID, the Styrmin, Python and operating system versions, the number of clusters, environments and deployments, and each loaded application driver version with its name as written and the number of deployments that use it. Turn it off with the Helm value `styrmin.telemetry.enabled: false`, `STYRMIN_TELEMETRY_ENABLED=false` or `DO_NOT_TRACK=1`, and view the exact report data, without sending it, with `styrmin telemetry show` in the server pod; see [Telemetry & privacy](https://styrmin.pages.dev/docs/reference/telemetry#server-telemetry).
