Removed the `component_env_vars` driver template filter. A driver `values.j2.yml` that still calls it now fails rendering with an error that names the [migration guide](https://styrmin.pages.dev/docs/drivers/migrating-env-vars), so a deployment pinned to an unmigrated driver version fails on its next change (including the redeploy an environment env var edit triggers) until it is upgraded to a driver version that declares component containers.
