Stopped passing the S3 access key and secret key of a backup storage location to the `sync-bsl-create` and `sync-bsl-update-credentials` flows as flow-run parameters, which the Prefect server stores and shows in its UI and API. Styrmin now saves the keys in a Prefect Secret block named `styrmin-bsl-<id>-credentials`, the flows read them from it, and deleting the location deletes the block. Flow runs started by earlier versions still show the keys until Prefect deletes them; to make those keys useless, rotate them in your object storage and update the location.
