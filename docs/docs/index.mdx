## Welcome to the Styrmin docs

Styrmin is an **application platform that manages the full lifecycle of
your infrastructure automation stack** — Infrahub, Ansible, Grafana,
Prometheus, and the tooling around them — as one system, not one
application at a time.

The docs are organised by what you're trying to do. Pick the entry
point that matches your goal; the sidebar on the left has everything in
order.

### Where to start

### The sections, at a glance

- **[Introduction](./introduction/why-styrmin.md)** — what Styrmin is,
  who it's for, how it compares to ArgoCD/Flux/Helm, and the platform

- **[Installation](./installation/index.mdx)** — Quickstart, the
  prerequisites every install shares, and per-platform install guides
  (DigitalOcean, GKE, local vCluster).
- **[Drivers](./drivers/loading-drivers.md)** — how to load a driver,

  [Concepts and Architecture](./concepts-and-architecture/what-is-a-driver.md).
- **[Operations](./operations/index.md)** — clone an environment, back
  up a stack, restore from backup, run an upgrade. The day-2 flows
  Styrmin was built for.
- **[Concepts and Architecture](./concepts-and-architecture/index.md)**

- **[Changelog](./changelog.md)** — what's changed, release by release.

If you're not sure which page to read first, [**Why
Styrmin?**](./introduction/why-styrmin.md) is the most common entry
