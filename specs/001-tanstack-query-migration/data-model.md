# Data Model: Replace urql with TanStack Query

**Feature**: 001-tanstack-query-migration
**Date**: 2026-04-03

## Overview

This feature does not introduce new persistent data entities. It replaces the client-side data fetching and caching layer. The "data model" here describes the client-side configuration objects and their relationships.

## Client-Side Entities

### QueryClient

The central configuration object for all data fetching behavior.

**Attributes**:
- `defaultOptions.queries.staleTime`: Duration (ms) before cached data is considered stale. Default: 0 (always stale, matching current urql behavior with no TTL).
- `defaultOptions.queries.gcTime`: Duration (ms) before unused cached data is garbage collected. Default: 5 minutes.
- `defaultOptions.queries.retry`: Number of retry attempts on failure. Default: 3 with exponential backoff.
- `defaultOptions.queries.refetchOnWindowFocus`: Whether to refetch when browser tab regains focus. Default: true.
- `defaultOptions.mutations.retry`: Number of retry attempts for mutations. Default: 0 (no retries — mutations should not be blindly retried).

**Relationships**: Provides context to all query and mutation hooks via `QueryClientProvider`.

### GraphQL Fetcher

A function that executes GraphQL operations against the backend API.

**Attributes**:
- `endpoint`: The GraphQL API URL (`/graphql`, matching current urql config).
- `headers`: Default headers for all requests (e.g., `Content-Type: application/json`).

**Relationships**: Used by all generated query and mutation hooks as the transport layer.

### Generated Query Hook (per operation)

One hook per `.graphql` query file (14 total). Generated by codegen.

**Attributes**:
- `queryKey`: Auto-generated from operation name + variables. Enables cache management.
- `queryFn`: Calls the GraphQL fetcher with the operation document and variables.
- `enabled`: Optional boolean to conditionally execute (replaces urql `pause`).
- `refetchInterval`: Optional polling interval in ms (replaces `useAutoRefresh`).

**Relationships**: Reads from QueryClient cache. Returns `{ data, isLoading, error, refetch }`.

### Generated Mutation Hook (per operation)

One hook per `.graphql` mutation file (14 total). Generated by codegen.

**Attributes**:
- `mutationFn`: Calls the GraphQL fetcher with the operation document and variables.
- `onSuccess`: Callback to invalidate related query keys after successful mutation.

**Relationships**: Writes to QueryClient cache via invalidation. Returns `{ mutate, mutateAsync, isPending, error, data }`.

## State Transitions

No state machines involved. Query states follow TanStack Query's built-in lifecycle:
- **idle** → **loading** → **success** | **error**
- **success** → **stale** → **fetching** (background refetch) → **success**
- **error** → **fetching** (retry) → **success** | **error**
