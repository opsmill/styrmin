## Executive Summary

The spec solves a stated problem from issue #272 with a narrow, additive design:

- Three nullable columns.
- One read-only GraphQL extension.
- One shared React component with a fallback.
- An E2E that extends an existing suite instead of booting a new stack.

The product decisions (external URL, icon + description + links, generic-icon fallback) came from the user and are respected.

One must-address gap: two committed test fixtures use the `icon: xxxx` placeholder, so the stricter validation would break four existing test modules, including one E2E, and the plan does not list them. The other findings are low-risk refinements:

- Decorative alt text.
- Cleanup and an intrinsic image size in the E2E.
- A separate "Changed" changelog entry for the stricter validation.
- An explicit note that a driver author can see who views the drivers page.
