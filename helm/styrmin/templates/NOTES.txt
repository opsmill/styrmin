To access the Styrmin GraphQL API, run these commands:

  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "styrmin.name" . }},app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=server" -o jsonpath="{.items[0].metadata.name}")
  export CONTAINER_PORT=$(kubectl get pod --namespace {{ .Release.Namespace }} $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME 8000:$CONTAINER_PORT

Then access: http://localhost:8000/graphql

=============================================================================
GETTING STARTED
=============================================================================

1. Wait for all pods to be ready:
   kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/instance={{ .Release.Name }}" -w

2. Check the Styrmin server logs:
   kubectl logs --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "styrmin.name" . }},app.kubernetes.io/component=server" -f

3. Check the Styrmin agent logs:
   kubectl logs --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "styrmin.name" . }},app.kubernetes.io/component=agent" -f

=============================================================================
TELEMETRY
=============================================================================
{{- if .Values.styrmin.telemetry.enabled }}

Telemetry is on: Styrmin sends one anonymous report a day to {{ .Values.styrmin.telemetry.endpoint | default "OpsMill" }}.

To view the report, run:
  kubectl exec --namespace {{ .Release.Namespace }} deploy/{{ include "styrmin.server.fullname" . }} -c styrmin-server -- styrmin telemetry show

To turn telemetry off, run:
  helm upgrade {{ .Release.Name }} <chart> --version {{ .Chart.Version }} --namespace {{ .Release.Namespace }} --reuse-values --set styrmin.telemetry.enabled=false
where <chart> is the chart you installed, for example oci://registry.opsmill.io/opsmill/chart/styrmin.
{{- else }}

Telemetry is off (styrmin.telemetry.enabled=false). Styrmin sends no reports.
{{- end }}
