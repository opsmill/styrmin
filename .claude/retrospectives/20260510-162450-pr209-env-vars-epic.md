## Local-only notes

- **R6 (loop staleness):** wakeup prompts can fire after work is complete. Always check current branch state before re-doing the named work; recognise stale wakeups by comparing the wakeup message's expected next step against the actual git/CI state.
- **R7 (pdb EOF):** the `sleep infinity | pytest --pdb` pattern documented in `AGENTS.md` doesn't fully hold pdb open in the agent's bash backgrounding harness — pdb receives EOF and runs teardown after the test fails. The captured log under `/tmp/e2e-pdb.log` still contains the full pre-pause investigation dump (kubectl pods, services, logs), which is sufficient for post-mortem analysis. Don't expect to drive pdb interactively from a separate shell in this harness.
